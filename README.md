# Deník údržby

Aplikace (jeden soubor `index.html`) pro evidenci požadavků údržby. **Bez dat:** data a fotky jsou na vlastním serveru
uživatele a vidí je jen po přihlášení jeho účtem. V souboru není adresa serveru, klíč ani heslo – zadávají se při přihlášení
a zůstanou v prohlížeči.
